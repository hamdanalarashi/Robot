# نظام التعرف على المتحدث بالكاميرا
## شرح مفصل بالعربية

---

## 🎯 نظرة عامة

هذا النظام يجمع بين **الصوت** و**الفيديو** لتحديد **من يتحدث** في الوقت الفعلي:
- **ReSpeaker Mic Array** يحدد اتجاه الصوت (Direction of Arrival)
- **الكاميرا** تتعرف على الوجوه والأشخاص
- **النظام** يدمج البيانات ليحدد المتحدث النشط

---

## 📋 كيف يعمل النظام؟

### المرحلة 1️⃣: التقاط البيانات الصوتية (ReSpeaker)

```
🎤 ReSpeaker → يلتقط الصوت من جميع الاتجاهات
              ↓
        يحسب زاوية المتحدث (0-359 درجة)
              ↓
        يكتشف نشاط الصوت (هل هناك شخص يتكلم؟)
```

**مثال:**
- شخص يتحدث من اليمين → الزاوية: 90°
- شخص يتحدث من الأمام → الزاوية: 0°
- شخص يتحدث من اليسار → الزاوية: 270°

---

### المرحلة 2️⃣: التقاط البيانات البصرية (الكاميرا)

```
📷 الكاميرا → تلتقط صورة فيديو مباشرة
              ↓
    OpenCV يكتشف الوجوه في الصورة
              ↓
    يحسب موقع كل شخص في الإطار
              ↓
    يحول الموقع إلى زاوية (بناءً على FOV)
```

**مثال حساب الزاوية:**
```
إذا كان الشخص في:
- منتصف الكاميرا → زاوية = 0°
- يمين الكاميرا → زاوية = +35° (حسب FOV)
- يسار الكاميرا → زاوية = -35°
```

---

### المرحلة 3️⃣: دمج البيانات (DoA-Matching)

```
🎤 زاوية ReSpeaker: 45°
📷 الأشخاص المكتشفون:
   - شخص 1: زاوية 47° ← فرق = 2° ✅
   - شخص 2: زاوية 120° ← فرق = 75° ❌

النتيجة: شخص 1 هو المتحدث النشط!
```

**الخوارزمية:**
1. احصل على زاوية DoA من ReSpeaker
2. احصل على زوايا جميع الأشخاص من الكاميرا
3. احسب الفرق بين زاوية DoA وكل شخص
4. الشخص الأقرب (الفرق الأصغر) هو المتحدث
5. إذا كان الفرق > 30° → لا يوجد تطابق

## 📐 الحسابات الرياضية

### 1. تحويل موقع الشخص في الكاميرا إلى زاوية

```python
# معادلة الحساب:
موقع_نسبي = (مركز_الشخص_x) / (عرض_الإطار)
              # النتيجة: 0.0 (يسار) إلى 1.0 (يمين)

إزاحة_الزاوية = (موقع_نسبي - 0.5) × مجال_الرؤية
                 # مثال: (0.7 - 0.5) × 70° = 14°

الزاوية_النهائية = (اتجاه_الكاميرا + إزاحة_الزاوية) % 360
```

**مثال عملي:**
```
- مجال رؤية الكاميرا (FOV) = 70°
- شخص في موقع x = 480 من 640 بكسل
- موقع_نسبي = 480 / 640 = 0.75
- إزاحة = (0.75 - 0.5) × 70 = 17.5°
- الزاوية النهائية = 0 + 17.5 = 17.5°
```

### 2. حساب المسافة الزاوية

```python
# أقصر مسافة بين زاويتين (تعامل دائري)
فرق = |زاوية1 - زاوية2|

إذا كان الفرق > 180:
    فرق = 360 - فرق

# مثال:
# زاوية1 = 10°, زاوية2 = 350°
# فرق = |10 - 350| = 340°
# 340 > 180 ← فرق = 360 - 340 = 20° ✅
```

## 🎨 واجهة العرض

### معلومات الشاشة:

```
┌─────────────────────────────────────────────┐
│ 🎤 DoA: 45°  |  🗣️ كلام  |  👥 أشخاص: 2 │  ← شريط المعلومات
│            النشط: شخص 1                    │
├─────────────────────────────────────────────┤
│                                             │
│   ┌──────────────┐      ┌──────────────┐   │
│   │  شخص 1       │      │  شخص 2       │   │
│   │  (يتحدث)     │      │              │   │  ← إطارات الكشف
│   │  45°         │      │  120°        │   │
│   └──────────────┘      └──────────────┘   │
│              ↗ سهم الاتجاه                 │  ← سهم DoA
│                              FPS: 28.5     │  ← الأداء
└─────────────────────────────────────────────┘
```

### رموز الألوان:
- 🟢 **أخضر** = المتحدث النشط (تطابق + صوت)
- 🔵 **أزرق** = شخص آخر مكتشف
- 🟡 **أصفر** = سهم اتجاه DoA

## 🎓 المفاهيم التقنية

### DoA (Direction of Arrival)
تقنية لتحديد اتجاه مصدر الصوت باستخدام مصفوفة ميكروفونات متعددة

### FOV (Field of View)
مجال الرؤية - الزاوية الأفقية التي تراها الكاميرا (عادة 60-80°)

### Voice Activity Detection (VAD)
خوارزمية لكشف وجود صوت بشري (تحدث) من عدمه

### Haar Cascades
خوارزمية كلاسيكية لكشف الوجوه بسرعة عالية

### Person Tracking
تتبع الأشخاص عبر الإطارات للحفاظ على نفس ID
